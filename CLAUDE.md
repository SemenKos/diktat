# Diktat: заметки для разработки

- Статический сайт без сборки и зависимостей. `logic.js` содержит чистые функции без DOM (`parseText`, `checkAnswer`, `lcsMarks`), `app.js` отвечает за интерфейс.
- Данные хранятся в `localStorage` под ключом `diktat.v1`: `{ lessons: [{id, name, created, words: [{id, de, ru, ok, bad, err, last}]}], settings, days }`. `err` — «трудность» слова: +2 за ошибку при написании, +1 при выборе, −1 за верный ответ. Слова с `err > 0` попадают в «Трудные слова».
- Редактор урока — два шага в объекте `draft` (только в памяти): `text` (вставить список) → `table` (проверить переводы). Строки таблицы обновляются точечно (`refreshRow`), а не перерисовкой экрана, чтобы не сбивать фокус и клавиатуру, пока подгружаются переводы.
- Фото: шаг `photo` в `draft` (`draft.photo = {shots, lines, busy, error}`). Tesseract.js 5.1.1 грузится с jsdelivr лениво (`loadTesseract`), один воркер `deu+rus` на всё время работы, PSM 6, чтобы строки читались поперёк колонок. Строки чистит `cleanOcrLine`, сомнительные помечает `ocrFlag` (оба в `logic.js`).
- Переводы: `translate.js` → `translateWord(de)`. Сначала Викисловарь (пакетно, по одному запросу за раз, повтор при 429), потом MyMemory, только если статьи нет. Ошибка Викисловаря — это «нет связи», машинный перевод в этом случае не подставляется. Кэш в `localStorage` под ключом `diktat.tcache.v1`.
- Роутинг на хэше: `#/`, `#/lesson/ID`, `#/edit/ID|new`, `#/settings`, `#/session`, `#/result`. Состояние тренировки (`session`) живёт только в памяти.
- Клики обрабатываются делегированием: `data-go="путь"` для навигации, `data-act="имя"` для вызова `actions[имя]`.
- После каждого изменения файлов поднимайте `CACHE` в `sw.js`. Новые файлы добавляйте в `ASSETS`.
- После правок `logic.js` запускайте `node tests/logic.test.js`, после правок `translate.js` — `node tests/translate.live.js`.
- Интерфейс на русском и рассчитан на телефон: ширина экрана от 360px.
