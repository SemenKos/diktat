# Diktat — немецкие слова к диктанту

Приложение для телефона, чтобы готовиться к словарному диктанту по немецкому. Похоже на Duolingo, но набор слов для урока задаёшь сам. Одна страница без сборки и без сервера: работает офлайн и устанавливается как приложение (PWA). Все данные хранятся в браузере на устройстве.

## Возможности

- **Свои уроки.** Вставляешь список немецких слов, по одному на строку. Переводы приложение находит само, а потом показывает таблицу на проверку:
  - перевод из немецкого Викисловаря помечен ✓, машинный перевод (если слова нет в словаре) — ⚠ «проверь»;
  - под каждым словом кнопки с другими значениями: нажатие добавляет вариант к переводу или убирает его (`бежать, бегать`);
  - любое поле можно исправить руками, строку — удалить или добавить;
  - если у существительного забыт артикль, приложение предложит его (`Fahrrad` → `das Fahrrad`);
  - урок не сохранится, пока у всех слов нет перевода.

- **Список с фото.** Кнопка «📷 Распознать с фото» на шаге ввода: можно сфотографировать страницу учебника или тетради (или выбрать несколько фото сразу). Распознанные строки показываются списком:
  - любую строку можно исправить, удалить ✕ или добавить новую (кнопкой или Enter в строке);
  - сомнительные строки помечены ⚠: плохо распознаны, похожи на заголовок или на предложение; их можно удалить одной кнопкой;
  - колонки «слово — перевод» без разделителя разбираются сами, путаница латиницы и кириллицы (`Наus` → `Haus`) исправляется;
  - дальше слова попадают в таблицу проверки переводов.

  Свой перевод можно сразу написать через разделитель: `der Hund — собака`. Разделители: `—`, ` - ` (с пробелами), `=`, `;`, табуляция, поэтому можно копировать прямо из таблицы. Если стороны перепутаны (`собака — der Hund`), приложение поменяет их само.
- **«Пройти урок»** в 4 этапа:
  1. немецкое слово → выбрать русский перевод из 4 вариантов;
  2. русское слово → выбрать немецкое;
  3. написать немецкое слово самому;
  4. работа над ошибками: снова написать слова, в которых ошибся.

  Слово с ошибкой возвращается через 2–3 задания, пока не ответишь правильно.
- **Отдельные режимы:** перевод, выбор слова, написание, диктант на слух (озвучка через синтез речи браузера, можно медленно), ошибки урока, контрольная (на слух, без подсказок и повторов, с оценкой 2–5 и разбором ответов).
- **Подсказки при ошибке:** неверный или забытый артикль, умлаут или ß, маленькая буква у существительного, опечатка в 1–2 буквах. Ошибочные буквы подсвечиваются.
- Кнопки `ä ö ü ß Ä Ö Ü` над полем ввода.
- **Трудные слова:** слова с ошибками из всех уроков. Слово уходит из списка после нескольких правильных ответов.
- Серия дней занятий, процент выученного по уроку, резервная копия в файл, «Поделиться списком слов».

## Формат слов

```
der Hund                       перевод найдётся сам
der Hund — собака              свой перевод
die E-Mail - письмо            дефис внутри слова не мешает
anfangen / beginnen — начинать  принимается любой вариант
der Hund (-e) — собака          текст в скобках писать не обязательно
```

## Запуск

Откройте `index.html` в браузере. Чтобы приложение можно было установить на телефон и пользоваться им без интернета, его нужно открывать с сайта по https: браузер не регистрирует service worker для страницы, открытой как файл.

### GitHub Pages

1. Загрузите файлы в корень репозитория.
2. Откройте **Settings → Pages → Build and deployment**, выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
3. Через минуту приложение будет доступно по адресу `https://<логин>.github.io/<репозиторий>/`.
4. На телефоне откройте этот адрес и выберите «Добавить на главный экран» (Android: меню Chrome → «Установить приложение»; iPhone: Safari → «Поделиться» → «На экран „Домой“»).

Для озвучки на телефоне должен быть установлен немецкий голос синтеза речи (Android: Настройки → Спец. возможности → Синтез речи). Приложение подскажет в настройках, если голос не найден.

Для проверки на своём компьютере:

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.

### Тесты

```bash
node tests/logic.test.js
```

Живая проверка поиска переводов (нужен интернет):

```bash
node tests/translate.live.js der\ Hund laufen Fahrrad
```

## Распознавание фото

Работает прямо на телефоне через [Tesseract.js](https://github.com/naptha/tesseract.js) (немецкий + русский), фото никуда не отправляется. При первом использовании с CDN jsdelivr скачивается около 8 МБ (библиотека и языковые данные), потом всё берётся из кэша браузера. Лучше всего распознаётся ровное, хорошо освещённое фото, где список занимает почти весь кадр.

## Откуда берутся переводы

1. [Немецкий Викисловарь](https://de.wiktionary.org) через его открытый API: русские переводы из раздела «Übersetzungen» и род существительного. Слова запрашиваются пакетами до 50 штук, чтобы не упереться в ограничение частоты запросов.
2. Если статьи нет — машинный перевод [MyMemory](https://mymemory.translated.net) (бесплатно, без ключа, около 5000 символов в день с одного устройства).

Оба сервиса работают прямо из браузера, без своего сервера. Найденные переводы кэшируются на устройстве. Без интернета переводы можно вписать вручную.

## Файлы

```
index.html          разметка страницы
app.js              интерфейс: экраны, тренировка, редактор, распознавание фото, хранение данных
logic.js            разбор списка слов, проверка ответов, разбор ответов словарей, чистка строк с фото (без DOM, покрыт тестами)
translate.js        запросы к Викисловарю и MyMemory, кэш переводов
style.css           стили, светлая и тёмная тема
manifest.json       описание приложения для установки
sw.js               service worker: офлайн-кэш
icon.svg, icon-*.png  иконки
tests/              тесты: logic.test.js (без сети), translate.live.js (через интернет)
```

## При изменениях

После правки файлов увеличьте номер кэша в `sw.js` (`const CACHE = 'diktat-vN'`). Если добавляете новый файл, впишите его и в список `ASSETS` в `sw.js`.
